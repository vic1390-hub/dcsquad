How to get a Google Client ID (5 steps)
  1. Go to console.cloud.google.com and create a new project (e.g. DC Squad)
  2. Enable the Google Calendar API — search for it in the API Library
  3. Go to APIs & Services → Credentials → Create Credentials → OAuth client ID
  4. Choose Web application. Under Authorised JavaScript origins add the full path to this HTML file (e.g. http://localhost:8000 or your hosted URL)
  5. Copy the Client ID (ends in .apps.googleusercontent.com) and paste above

Your keys stay in your browser — never stored or sent anywhere except Google & Anthropic.
